# Navegação regional — Hidrodinâmica II

Aplicativo para extrapolação da resistência modelo–protótipo pelos métodos de Froude e Hughes. Tema visual inspirado na navegação fluvial amazônica.

## Utilização

Abra o site, ajuste os parâmetros e informe os pares de velocidade e resistência total do modelo. Os resultados, gráficos e a memória de cálculo são atualizados automaticamente. O botão **Planilha Excel** disponibiliza a planilha com os cálculos, gráficos e verificação do exercício.

O aplicativo funciona inteiramente no navegador, sem cadastro e sem enviar os parâmetros para um servidor.

## Hipóteses

Linha de atrito ITTC-1957 nos dois métodos. Fator de forma constante nas duas escalas no método de Hughes, conforme o exercício de referência. A potência calculada é a potência efetiva. As propriedades da água do protótipo seguem o exercício fornecido.
